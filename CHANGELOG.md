# Changelog

Notable changes to ZeroFee. Dates are UTC. The contract's releases are numbered on chain (`release_version()`); the app
is released from `main`.

## Unreleased

- Self-hosting in one command: `make selfhost` (or `bash tools/selfhost/run.sh`) builds the web app and serves it with
  its quote relay on one local port; every key is optional and read from `.env` (see `.env.example`).
- Licence: Apache-2.0, with a NOTICE for TradingView Lightweight Charts.
- Repository files for contributors: SECURITY.md, CODE_OF_CONDUCT.md, issue and pull request templates, CI.
