# Shell problems

Problems the shell (apps/web) shows itself, outside any app. Every Problem has a code, three plain parts and a test.

| Code | What happened | Money | Next step |
|---|---|---|---|
| `shell.app.crashed` | (App name) stopped working. Only that app's page shows this; the other apps keep working. The error is logged to the console, never shown. | safe: in your account | Try again (retry): mounts that app afresh |
| `shell.app.hidden` | That part of ZeroFee isn't in this build yet. | not involved | Go back (nothing) |
